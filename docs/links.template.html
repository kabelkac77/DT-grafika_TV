Jak přidat odkaz

Otevři ODKAZY.md v repozitáři, přidej řádek a ulož. Stránka se přegeneruje sama.

- [Název odkazu](https://adresa) — krátký popis

Řádek ## Název skupiny založí novou skupinu; odkazy pod ním do ní spadnou.

Stránka se generuje ze souboru ODKAZY.md příkazem npm run dashboard.

Odkazy vedou i mimo repozitář; obsah za nimi nekontrolujeme.

Zadání se od načtení této stránky změnilo.
