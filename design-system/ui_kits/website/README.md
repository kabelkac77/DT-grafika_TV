# SVDT Website UI kit

Interactive recreation of the svdtpribram.cz homepage and rider registration flow, built from this system's components (Header, Countdown, StatBand, Card, ScheduleRow, Podium, ResultsTable, PartnerWall, FormField, RadioGroup, Checkbox, Alert, Button, Footer).

Open `index.html`. Click **Registrace** in the header or hero to go to the registration form; submit it to see the success alert; **Zpět na web** returns home.
